# KTools: Auto Loot

WoW Legion 7.3.5 — модуль автоматического сбора добычи.

---

## Команда быстрого доступа
- /ktloot

---

## Шапка

- [ ] Активация аддона и всех модулей одной кнопкой
- [ ] Список выбора профилей
- [ ] Кнопка создания профилей
- [ ] Список выбора профиля для удаления
- [ ] Кнопка открытия окна импорта
- [ ] Кнопка открытия окна экспорта
- [ ] Кнопка переключения окна быстрых настроек и пользовательских настроек

---

## Быстрое меню

### Общие настройки

- [ ] **Реагенты** — подбирает все возможные реагенты для профессий
- [ ] **Рецепты** — подбирает все возможные рецепты для профессий
- [ ] **Маунты** — всех верховых животных из лута
- [ ] **Питомцы** — всех питомцев
- [ ] **Золото** — любое золото из добычи
- [ ] **Валюта** — любую валюту, которая есть в окне персонажа (ресурсы оплота класса, аспектитовые кристаллы)
- [ ] **Сила артефакта** — предметы, повышающие силу артефактного оружия
- [ ] **Квестовые предметы**

### Настройки предметов по качеству, которые могут быть проданы вендору

- [ ] Конкретное качество предметов
- [ ] `ilvl >= {value}` — собирать предметы с уровнем ≥ указанного
- [ ] **NoB** — *Not on Bind* — непривязываемые предметы
- [ ] **BoE** — *Bind on Equip* — персональный при надевании
- [ ] **BoP** — *Bind on Pickup* — персональный при поднятии

---

## Пользовательский список

### Раздел добавления предмета

- [ ] Активность списка
- [ ] `id` — поле ввода ID предмета
- [ ] Поле ввода названия предмета (либо ссылки через Shift + клик по предмету)
- [ ] `>= ilvl` — поле ввода минимального ilvl предмета
- [ ] `ok` — кнопка добавления предмета

### Список добавленных предметов

- [ ] Кнопка активации предмета
- [ ] Интерактивная иконка (наведение мышки выдаёт подсказку)
- [ ] `id` — поле ID предмета
- [ ] Название предмета (интерактивное название, являющееся ссылкой на предмет)
- [ ] `ilvl` — редактируемое поле для обновления минимального ilvl сбора предмета
- [ ] Тип предмета (только текст)
- [ ] Кнопка удаления предмета
